# RoleDiff on GitHub

**Repository:** `dc9-dev/rolediff`

**Tagline:** Test who can access what.

**About description:**

```text
Authorization regression tests for APIs. Compare access across users and roles with native Go and Rust libraries, a shared CLI format, and CI reports.
```

**Topics:** `security`, `api-security`, `authorization`, `bola`, `idor`, `go`, `rust`, `pentesting`, `devsecops`, `cli`

**Banner:** [rolediff-banner.png](assets/rolediff-banner.png)

**Polski opis:** RoleDiff sprawdza, czy konta testowe mają dostęp zgodny z oczekiwaną polityką aplikacji. Wykonuje wskazane żądania API, weryfikuje statusy i pola JSON oraz sygnalizuje regresje w CI. Repozytorium zawiera niezależne implementacje w Go i Rust.
